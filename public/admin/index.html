Webhooks

Outbound HTTP notifications for events like provider imports. Subscribers receive a signed JSON POST whose body the recipient should verify with HMAC-SHA-256 over the secret. See docs/webhooks.md for the event catalog and verification snippet.

Webhooks are currently disabled at the server level (WEBHOOKS_ENABLED=false). Subscriptions can still be managed but no events will be delivered until the server is restarted with webhooks enabled.
